## 0. 一句话总结

我们 fork 了当前**最好的公开方案**（ridge-sp，公榜 7.904），搭起了**完整的本地复现 + 秒级实验环境**，然后用一系列受控实验**逐条证伪**了几乎所有看似有希望的改进方向。即使是**唯一通过本地鲁棒性验证、且无训练偏差**的改进（空间构造重建第3分支，v6），公榜仍变差（8.130 > 7.904）。

**最深层的定论**：在这个比赛，**没有任何 train-only 本地验证（哪怕诚实 GroupKFold、分半稳健、无训练偏差）能预测公榜** —— 所有偏离 0.3/0.7 基线的改动（v3~v6）公榜全部变差。根因是泄漏 + GBDT OOF 乐观偏差 + 位置/分布偏移，三者叠加且都本地不可测。

核心结论：这个 fork 已**确定地到达天花板**（v1=7.904 是最优，每个偏离都更差）；前排 5-6 分的优势主要来自**数据结构利用（井匹配/泄漏）+ 公榜过拟合**，而非"更强的 tabular ML"；私榜可能大洗牌。**最有价值的产出不是名次，而是用实验把天花板和"本地CV不算数"这件事钉死了。**

## 1. 比赛理解

### 1.1 任务
- 每口**水平井（horizontal well）**沿轨迹有 `MD/X/Y/Z/GR` 等测井数据；`TVT`（True Vertical Thickness，真垂直厚度，即井在地层中的相对位置）在**预测起点 PS 之前已知**（列 `TVT_input`），**PS 之后要预测**。
- 还给一口**典型井（typewell / vertical reference）**，有 `TVT` vs `GR` 的参考曲线。
- 本质：用 GR 曲线 + 典型井相关性 + 几何，判断水平井在地层厚度中的位置。**是"带物理约束的序列对齐/地层导向"问题，不是普通 tabular regression。**

### 1.2 数据结构（实测确认）
- 训练水平井列：`MD, X, Y, Z, ANCC, ASTNU, ASTNL, EGFDU, EGFDL, BUDA, TVT, GR, TVT_input`
- **6 个地层面列**（`ANCC/ASTNU/ASTNL/EGFDU/EGFDL/BUDA`，以负 TVD 存储）—— **仅训练井有**，测试井没有。
- 测试水平井列：仅 `MD, X, Y, Z, GR, TVT_input`（TVT 被隐藏）。
- 地层对应 **Eagle Ford / Buda**（`EGFDU/EGFDL` = 上/下 Eagle Ford 顶界，`BUDA` = Buda 界面）。
- 训练井 773 口；本地 `test/` 只有 **3 口**（且都在训练集里，见泄漏）。

### 1.3 评分与机制
- 评分：预测段 dTVT = manualTVT − predictedTVT 的 **pooled RMSE**。
- **Code competition**：提交 Notebook，Kaggle 重跑生成 `submission.csv`。
- 每天 **5 次**提交，最终选 **2 个**提交算私榜。
- 公榜约占测试集 **26%**，最终奖牌按另外 **74% 私榜**算（此数据来自第三方调研，未在规则页直接证实，但与"奖牌按私榜算"一致）。

## 2. 复现的公开方案架构（fork 自 lightningv08 / ravaghi / romantamrazov）

```
最终预测 = 0.3 × GBDT分支(tvt_1) + 0.7 × 启发式分支(tvt_2)
```
- **GBDT 分支（0.3）**：LightGBM×3 + CatBoost×2 → Ridge 叠加，输入 198 个特征（含 pf_ancc、pf_z、beam、dense_ancc 空间特征、NCC 等）。后接 `apply_pp`（按 md_since 的指数 ramp）+ `sg_smooth`。**模型是预训练产物，加载不重训。**
- **启发式分支（0.7）**：128 种子粒子滤波似然集成 + 14 配置 Beam Search + per-well selector 变体融合。
  - **可见井**（在训练集里）：走 `tvt_from_contacts` 物理模型（用训练井的 EGFDU + TVT，≈泄漏）。
  - **非可见井**：走 selector 启发式。

## 4. 关键诊断发现（都经实测）

1. **数据泄漏是"完美"的**：本地 3 口测试井 literally 就是训练井（TVT 被隐藏）。已知段 `train_TVT − test_TVT_input` 最大差 = **0.00000**；直接抄训练井 TVT 做预测，**RMSE = 0.000000（满分）**。物理模型 0.005，selector（无泄漏）6.48。
2. **公榜分数被泄漏部分驱动**：倒推 `7.904 ≈ √((1−x)·sel²)`（sel≈10）→ 约 **37% 的公榜测试井被"打中"近零误差**，63% 是难井（selector ~10）拖着。
3. **运行噪声 ~0.07**：**完全相同的代码**两次评分 7.904 vs 7.976（差 0.072）。来源：GBDT 特征里的 numba PF（`run_pf_ancc/pf_z`）用全局随机态 + 并行 → 每次特征略不同。本地实测预测值逐点差异 RMSE 0.28。**噪声 > 银牌余量（0.04）。**
4. **本地无泄漏 CV 不能预测公榜（关键障碍）**：本地最优融合权重是 0.5（9.59→9.37），但公榜实测 0.3 最优（见 §6 v4）。根因是**训练/测试分布偏移 + GBDT 的 OOF 乐观偏差**：GBDT 在训练井上的留出表现高估了它在不同分布的测试井上的表现；而 selector 是纯启发式（无训练偏差），表现一致。
5. **0.3 是公榜最优融合权重（双向 bracket 确认）**：0.2→8.030，0.3→7.904，0.5→8.092，两边都更差。公开作者调到位了。
6. **前排 5-6 的来源**（强推断）：把更大比例的井打进"近零误差桶"——靠**更广的井匹配/查表（指纹）**和**更强的空间构造重建**，外加**公榜过拟合**。**不是"更强的 tabular ML"。** 私榜若是真正 held-out 的新井，这些优势会塌方、榜单大洗牌。

### 5.1 终局认知：run 级噪声结构（v9/v9b/v10 的最大产出）
- 平均抽样紧(std 0.014)但均值差 → 由 Jensen 不等式反推：**公榜噪声主体是"run级共同偏置"**（整个 kernel 进程共享一次掷骰），K 平均只能压井级独立部分、压不掉 run 偏置。
- 推论①：公榜 draw 对私榜 draw 有预测力（同 run 偏置全井共享）→ 选定策略=直接选公榜最好的单跑。
- 推论②：v8 配置两 draw(7.893/7.976) vs v1 配置(7.904/7.976) → **同ID泄漏增益实际仅 ~0.01**，7.893 的主要成分是 run 运气；fork 大军 223 队的排名差异相当部分就是这个骰子。

### 5.2 最终选定（私榜2个名额）
**✅ v8 (53515890, 7.893) + v1 (53470321, 7.904)** —— 公榜最好的两个独立单跑。其余全部取消勾选。

## 6. 所有实验汇总（核心：逐条证伪）

| 实验 | 方法 | 本地结果 | 公榜/最终判定 |
|---|---|---|---|
| 自建粒子滤波（pf.py）| 从零 PF 追踪 TVT+Z | 15.8，劣于常数基线 | GR 信号太弱，弃 |
| DP/Viterbi 对齐（geosteer.py）| 平滑罚项的动态规划 | 18.8 劣于常数 | 罚 dip 幅度→塌成常数，弃 |
| 单 dip GR 搜索（dipsearch.py）| GR cost 最小化选 dip | 真 dip vs GR-dip 相关性 0.07 | GR 单点无法定 dip，弃 |
| 朴素空间 KNN（spatial.py）| 原始 TVT 空间插值 | RMSE ~160 | 不同井penetrate不同层、无共享基准，弃 |
| **XGBoost 加栈** | 给 ridge 栈加 2 个 XGB | OOF 10.371→10.390 **变差** | ridge OOF 过拟合，弃 |
| **后处理 hold/平滑/ramp** | 收缩到常数/Savgol | 小样本好→**全量数据无效** | 公开方案后处理已饱和，弃 |
| **分歧度自适应回退** | 高分歧点拉向 const/beam | 全部变差 | 失败是"自信地错"，分歧度抓不住，弃 |
| **灾难井检测** | 6% 井 RMSE>20 主导误差；集成分歧度 corr=0.39 | 似然/分歧度选对率 ~58%（≈瞎猜）| 现实选择只吃下 oracle 上限的 3%，弃 |
| **selector+pfz oracle** | 两追踪器去相关，oracle 上限 9.12(−1.87) | 现实选择吃不下 | 信息存在但取不出，弃 |
| **#6 残差重构** | GBDT 学 selector 残差 | 残差可学(corr 0.369) 但 sel+残差(9.78) 不如现有 blend(9.59) | 现有 blend 已用重型集成的隐式残差，弃 |
| **全局融合权重调** | 0.3/0.7 → 0.5 | 本地 9.59→9.37 | **公榜变差(v4)**：本地反预测，弃 |
| **per-well domain 调权**（GPT建议）| 非典型度→少信 GBDT | corr(非典型度, GBDT劣势)=−0.028 | 假设不成立，弃 |
| **Eagle Ford 地质护栏** | 夹典型井 TVT 范围 | Δ=0.0000（真值 0% 越界）| 空操作，弃 |
| **降方差/固定种子** | 量化噪声 | 0.28 预测噪声 → 仅 ~0.005 评分影响 | 止损不进攻，弃 |
| **外部数据/方法扫描** | 高分 notebook + Dataset | 公开最好=我们的 fork；DWT(9.25)/TCN(17.5) 更差 | 无可用外部资源，前排私有 |
| **✅ 空间构造重建（方向②）** | 地层面 IDW 插值 → TVT=C−(Z−面)，C 用 TVT_input 标定 | 单独 24(噪声大) 但 0.08 权重 blend **固定gbdt=0.3 从 9.56→9.31**；**分半 4/4 种子一致改善 +0.08~0.38** | **唯一通过鲁棒性验证、无训练偏差→可transfer**，已做成 v6 提交 |

## 7. 结论与建议

### 7.1 核心结论
1. **这个 fork 已接近实践天花板**：所有"调权重/加模型/换追踪器/后处理"的改进都被实测证伪。
2. **本地无泄漏 CV 对涉及 GBDT 的改动不可信**（分布偏移 + OOF 乐观）；但对**纯启发式信号**（selector、spatial）**可信且可 transfer**。
3. **噪声(0.07) > 银牌余量(0.04)**：公榜微调本质是赌噪声。
4. **前排优势是数据结构利用 + 空间重建 + 过拟合，不是 tabular ML**；私榜可能大洗牌。
5. **唯一有验证支撑的进攻方向 = 空间构造重建（v6）**，因为它是正交的、无训练偏差的信号。

### 7.2 最终提交选择建议
- 若 v6 ≥ v1（没改善）：**选定 v1(7.904) + v3(7.934)**（两个最好公榜分，本质同方案的稳健变体）。
- 若 v6 < v1（spatial transfer 成功）：**选定 v6 + v1**（v6 进攻 + v1 兜底）。
- **不选** v4(8.092)/v5(8.030)。

### 7.3 若临近截止想再冲（性价比从高到低）
1. **把 spatial 重建做得更好**（kriging/GP 替代 IDW、多面联合、各向异性）——唯一能本地诚实验证(留一井)、且可能 transfer 的硬骨头。CPU 即可，**不需要 GPU**。
2. **更广的井匹配（指纹）**——可能把更多井打进近零误差桶；但本地验证不了、且未必存在该机会。
3. **降方差**（固定 numba PF 种子 + 多跑平均）——保私榜不被坏运气踢下来，但只止损。

### 7.4 不建议
- 公榜小数点后微调（噪声 > 信号）。
- 迁移别盆地的 generic 测井数据（地质不跨田 transfer）。
- 深度序列模型（公开深度方案分数更差，井数有限易过拟合）。**GPU 不是瓶颈。**

## 8. 方法论收获

1. **本地验证循环是一切的基础**：搭好"秒级、诚实"的 CV 让我们能逐条证伪假设，而不是靠每天 5 次提交碰运气。
2. **鲁棒性闸门（跨井子样本分半验证）救命**：`hold` 实验在 40 井上看着好(−0.04)，全量数据一平均就消失；同样的闸门让 v6 的 spatial(4/4 一致)和其他幻觉区分开。
3. **诚实的负面结果有价值**：搞清"此路不通且为什么"，比盲目堆模型扎实。
4. **区分"本地可信 vs 不可信"的信号**：纯启发式(无训练偏差)的本地 CV 能 transfer；带训练的(GBDT)不能——这个区分是后期决策的关键。
5. **看清对手的分是怎么来的**：前排 5-6 主要是数据结构利用 + 过拟合，这个认知避免了把精力浪费在"做更强的树模型"上。
